# Litôranea Verde Essência

Crie do ZERO um site institucional completo e responsivo para a:

LITÔRANEA AMBIENTAL
Empresa Júnior de Ciências Ambientais — UFC

IMPORTANTE:
Este projeto deve ser desenvolvido do zero. Não dependa de nenhum site anterior ou código existente.

O objetivo é criar um site institucional moderno, profissional e visualmente marcante para apresentar a empresa, seus serviços, sua missão, seus valores e seus canais de contato.

==================================================
1. REGRA ABSOLUTA SOBRE IMAGENS
==================================================

NÃO utilize imagens geradas por inteligência artificial.

NÃO gere imagens com IA.

NÃO utilize imagens de pessoas, paisagens ou ambientes ambientais geradas artificialmente.

Se uma imagem for necessária:
- utilizar somente imagens reais fornecidas pelo usuário;
- utilizar a logo fornecida pelo usuário;
- ou utilizar elementos gráficos criados diretamente em HTML/CSS/SVG.

Caso não exista uma imagem real disponível, NÃO invente uma imagem.

É preferível criar uma composição visual utilizando:
- formas geométricas;
- elementos orgânicos em CSS/SVG;
- linhas;
- círculos;
- padrões;
- ícones vetoriais;
- tipografia;
- blocos de cor.

Não utilizar banco de imagens aleatórias apenas para preencher espaço.

A identidade visual deve funcionar muito bem mesmo sem fotografias.

==================================================
2. OBJETIVO DO SITE
==================================================

O site deve funcionar como uma apresentação institucional da Litôranea Ambiental.

Ele deve transmitir:

- sustentabilidade;
- profissionalismo;
- inovação;
- confiança;
- juventude;
- conexão com a universidade;
- preocupação ambiental.

O público inclui:
- empresas;
- produtores rurais;
- órgãos públicos;
- potenciais clientes;
- estudantes;
- profissionais da área ambiental;
- comunidade acadêmica.

Não criar sistema de login, cadastro, painel administrativo, e-commerce ou funcionalidades complexas.

É um site institucional.

==================================================
3. IDENTIDADE VISUAL
==================================================

Criar uma identidade visual baseada na logo da Litôranea Ambiental e nas referências visuais fornecidas.

A paleta deve fugir do aspecto excessivamente branco e neutro.

Utilizar principalmente:

- verde floresta / verde escuro;
- verde oliva;
- laranja queimado / laranja vibrante;
- creme;
- bege;
- branco;
- tons terrosos.

O verde escuro deve representar a parte ambiental e institucional.

O laranja deve funcionar como cor de destaque.

O creme e o bege devem criar áreas de respiro.

A combinação deve ser elegante e contemporânea.

NÃO utilizar:
- azul predominante;
- roxo;
- cores neon;
- gradientes exagerados;
- estética tecnológica genérica;
- visual excessivamente corporativo.

O site deve parecer relacionado à área ambiental.

==================================================
4. ESTILO VISUAL
==================================================

Quero uma estética:

"Empresa ambiental + universidade + sustentabilidade + design editorial moderno"

O site não deve parecer um template genérico de empresa.

Criar uma identidade própria.

Utilizar:
- bastante hierarquia tipográfica;
- títulos grandes;
- pequenas etiquetas em laranja;
- linhas decorativas;
- formas orgânicas;
- cards bem construídos;
- bordas arredondadas moderadas;
- espaços bem planejados;
- contraste entre seções claras e escuras.

Evitar excesso de elementos.

O objetivo é deixar o site VIVO, mas ainda profissional.

==================================================
5. NAVEGAÇÃO
==================================================

Criar um header fixo no topo.

Menu:

Início
Quem Somos
Serviços
Missão e Valores
Contato

Os itens devem levar às respectivas seções utilizando âncoras.

NÃO criar botões para obrigar o usuário a passar pelas seções.

NÃO criar setas de "descer".

NÃO criar botão "scroll down".

NÃO criar navegação em formato de apresentação/slideshow.

O usuário deve poder navegar livremente pelo site através do scroll manual.

O menu pode ter:
- hover;
- indicador da seção atual;
- mudança sutil de sombra/transparência ao rolar.

==================================================
6. HERO / INÍCIO
==================================================

Criar uma primeira seção forte e marcante.

Apresentar:

LITÔRANEA AMBIENTAL

Empresa Júnior de Ciências Ambientais — UFC

Texto:

"Soluções ambientais desenvolvidas com conhecimento, inovação e compromisso com a sustentabilidade."

Criar uma composição visual interessante sem utilizar fotografias.

Utilizar:
- verde escuro;
- laranja;
- creme;
- formas orgânicas;
- linhas;
- elementos circulares inspirados na identidade da logo.

A hero section deve causar uma boa primeira impressão.

Não deixar uma área enorme vazia.

Não exagerar na quantidade de informações.

==================================================
7. QUEM SOMOS
==================================================

Criar uma seção chamada:

QUEM SOMOS

Título:

"Conheça a Litôranea"

Texto:

"A Litôranea Ambiental é a nova Empresa Júnior do curso de Ciências Ambientais da UFC."

"Nascemos em 2026 com o propósito de aproximar a universidade do mercado de trabalho, oferecendo aos estudantes uma experiência prática por meio do desenvolvimento de soluções ambientais para empresas, produtores rurais e órgãos públicos."

Criar uma composição visual dinâmica.

Pode utilizar:
- números;
- pequenas informações de destaque;
- formas gráficas;
- elementos decorativos;
- linhas;
- blocos de texto.

Por exemplo, destacar visualmente:

2026
Ano de fundação

UFC
Universidade Federal do Ceará

Ciências Ambientais
Área de atuação

Não inventar outras informações institucionais.

==================================================
8. SERVIÇOS
==================================================

Criar uma seção:

SERVIÇOS

Apresentar os quatro serviços em cards:

--------------------------------

PRAD

Plano de Recuperação de Áreas Degradadas ou Alteradas

"Documento técnico voltado ao planejamento e à execução de ações para recuperação de áreas que sofreram degradação ou alteração ambiental."

--------------------------------

RAS

Relatório Ambiental Simplificado

"Estudo técnico utilizado no processo de licenciamento ambiental de atividades de pequeno porte e baixo potencial de impacto."

--------------------------------

EVA

Estudo de Viabilidade Ambiental

"Análise técnica preliminar que avalia a compatibilidade de um novo projeto com o meio ambiente e a legislação ambiental aplicável."

--------------------------------

PGRS

Plano de Gerenciamento de Resíduos Sólidos

"Plano voltado ao gerenciamento adequado dos resíduos sólidos, contemplando ações de planejamento, manejo e destinação ambientalmente adequada."

--------------------------------

Os cards devem possuir:

- sigla em destaque;
- título;
- descrição;
- ícone simples relacionado ao serviço;
- hover suave;
- pequeno deslocamento;
- sombra;
- mudança sutil de borda/cor.

Não criar efeitos exagerados.

Os cards devem parecer interativos e modernos.

==================================================
9. MISSÃO E VALORES
==================================================

Criar uma seção visualmente forte.

Utilizar predominantemente verde escuro.

Título pequeno:

MISSÃO

Missão:

"Valorizar os alunos e profissionais da área de Ciências Ambientais no mercado de trabalho."

Depois:

VALORES

Apresentar:

Sustentabilidade
Ética
Excelência
Inovação

Não apresentar apenas como uma lista simples.

Criar uma composição visual interessante.

Cada valor pode possuir:
- ícone;
- pequeno elemento gráfico;
- hover;
- animação de entrada;
- destaque laranja.

Utilizar contraste entre verde escuro, creme e laranja.

ENTRE EM CONTATO

O Instagram deve ser clicável.

NÃO criar botão de WhatsApp.

NÃO mencionar WhatsApp em nenhum lugar do site.

Não adicionar outros contatos que não foram fornecidos.

==================================================
12. UX / MICROINTERAÇÕES
==================================================

O site precisa parecer vivo.

Adicionar microinterações sutis:

Header:
- mudança de sombra ao rolar;
- hover nos links;
- indicador da seção atual.

Cards:
- elevação suave;
- mudança de borda;
- pequeno deslocamento;
- transição de 200–300ms.

Elementos:
- fade-in suave ao entrarem na tela;
- pequeno movimento vertical;
- transições discretas.

NÃO utilizar:
- animações exageradas;
- elementos girando;
- parallax pesado;
- animações infinitas;
- efeitos que prejudiquem a leitura;
- excesso de movimento.

O objetivo é criar uma sensação de refinamento.

==================================================
13. COMPOSIÇÃO VISUAL
==================================================

Uma das principais melhorias deve ser o ritmo visual.

Não deixar todas as seções com fundo branco.

Alternar entre:

- creme;
- branco;
- verde escuro;
- tons terrosos.

O laranja deve aparecer como elemento de destaque.

Exemplo de ritmo:

HERO
→ verde escuro / creme

QUEM SOMOS
→ creme / branco

SERVIÇOS
→ fundo claro com cards

MISSÃO E VALORES
→ verde escuro

CONTATO
→ creme / branco

FOOTER
→ tom terroso ou verde escuro

Isso deve criar uma experiência visual mais dinâmica.

==================================================
14. RESPONSIVIDADE
==================================================

O site deve ser completamente responsivo.

Desktop:
- layout amplo;
- cards em grid;
- boa utilização do espaço horizontal.

Tablet:
- adaptar grid;
- manter boa hierarquia.

Mobile:
- menu responsivo;
- cards em uma coluna;
- textos adaptados;
- espaçamentos menores;
- botões e links fáceis de tocar;
- nenhum elemento ultrapassando a tela.

A experiência mobile deve ser tratada como prioridade, não apenas como uma adaptação do desktop.

==================================================
15. ACESSIBILIDADE
==================================================

Garantir:

- contraste adequado;
- textos legíveis;
- tamanho de fonte confortável;
- navegação por teclado;
- estados de foco;
- alt text quando imagens reais forem utilizadas;
- HTML semântico;
- respeito à preferência de redução de movimento.

==================================================
16. TECNOLOGIA E QUALIDADE
==================================================

Criar uma implementação limpa e organizada.

Utilizar componentes reutilizáveis.

Evitar código duplicado.

Manter boa organização entre:
- componentes;
- estilos;
- dados;
- conteúdo.

O site deve carregar rapidamente.

Não adicionar bibliotecas desnecessárias apenas para efeitos visuais.

==================================================
17. REGRAS FINAIS
==================================================

IMPORTANTE:

1. Criar o site COMPLETAMENTE DO ZERO.

2. NÃO utilizar imagens geradas por IA.

3. NÃO criar fotografias artificiais.

4. Se não houver imagem real disponível, utilizar CSS/SVG/formas vetoriais.

5. NÃO adicionar WhatsApp.

6. NÃO criar botões para rolagem automática.

7. NÃO criar navegação em formato de apresentação.

8. O usuário deve navegar manualmente pelo site.

9. NÃO inventar informações sobre a Litôranea Ambiental.

10. NÃO substituir os textos institucionais fornecidos.

11. Não transformar o site em um template corporativo genérico.

12. Priorizar UX, hierarquia visual e identidade ambiental.

13. Utilizar as cores da identidade visual fornecida como principal referência.

14. O site deve parecer profissional o suficiente para ser apresentado oficialmente pela Empresa Júnior.

15. O resultado final deve transmitir:
SUSTENTABILIDADE + PROFISSIONALISMO + UNIVERSIDADE + INOVAÇÃO + JUVENTUDE.

Antes de finalizar, revise todas as seções para garantir que não exista nenhuma referência ao WhatsApp e que nenhuma imagem tenha sido gerada por IA.
